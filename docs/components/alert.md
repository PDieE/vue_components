# Alert 提示

<a class="VPButton medium alt" href="https://shadcn-vue.com/docs/components/alert" target="_blank" rel="noreferrer">shadcn-vue文档</a>

`UiAlert` 用于展示默认、信息、成功、警告和错误状态。

## 基础用法

<UiAlert variant="success">操作已完成</UiAlert>

```vue
<UiAlert variant="success">操作已完成</UiAlert>
```

## 组成与 API

使用 `UiAlertTitle` 和 `UiAlertDescription` 组织标题与说明；`variant` 支持 `default`、`info`、`success`、`warning`、`destructive`。
