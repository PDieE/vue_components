# Badge 徽标

<a class="VPButton medium alt" href="https://shadcn-vue.com/docs/components/badge" target="_blank" rel="noreferrer">shadcn-vue文档</a>
<a class="VPButton medium alt" href="https://reka-ui.com/docs/utilities/primitive" target="_blank" rel="noreferrer">reka-ui文档</a>

`UiBadge` 用于标识状态、类别或数量。

## 基础用法

<UiBadge variant="secondary">新</UiBadge>

```vue
<UiBadge variant="secondary">新</UiBadge>
```

## API

`variant` 支持 `default`、`secondary`、`destructive`、`outline`；`count` 可显示数量，`shape` 支持 `round` 与 `square`。
