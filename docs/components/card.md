# Card 卡片

<a class="VPButton medium alt" href="https://shadcn-vue.com/docs/components/card" target="_blank" rel="noreferrer">shadcn-vue文档</a>

`UiCard` 用于承载相关内容和操作。

## 基础用法

<div class="vp-demo">
<UiCard><UiCardHeader><UiCardTitle>标题</UiCardTitle></UiCardHeader><UiCardContent>内容</UiCardContent></UiCard>
</div>

```vue
<UiCard><UiCardHeader><UiCardTitle>标题</UiCardTitle></UiCardHeader><UiCardContent>内容</UiCardContent></UiCard>
```

## 组成

可使用 `UiCardHeader`、`UiCardTitle`、`UiCardDescription`、`UiCardContent`、`UiCardFooter` 与 `UiCardAction` 组织卡片。
