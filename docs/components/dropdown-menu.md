# Dropdown Menu 下拉菜单

<a class="VPButton medium alt" href="https://shadcn-vue.com/docs/components/dropdown-menu" target="_blank" rel="noreferrer">shadcn-vue文档</a> <a class="VPButton medium alt" href="https://reka-ui.com/docs/components/dropdown-menu" target="_blank" rel="noreferrer">reka-ui文档</a>

`UiDropdownMenu` 在触发元素旁展示一组操作。

## 基础用法

<div class="vp-demo">
<UiDropdownMenu><UiDropdownMenuTrigger>更多</UiDropdownMenuTrigger><UiDropdownMenuContent><UiDropdownMenuItem>编辑</UiDropdownMenuItem></UiDropdownMenuContent></UiDropdownMenu>
</div>

```vue
<UiDropdownMenu><UiDropdownMenuTrigger>更多</UiDropdownMenuTrigger><UiDropdownMenuContent><UiDropdownMenuItem>编辑</UiDropdownMenuItem></UiDropdownMenuContent></UiDropdownMenu>
```

## 组成

支持 Group、Label、Separator、CheckboxItem、RadioGroup、Sub 与 Shortcut 等菜单子组件。
