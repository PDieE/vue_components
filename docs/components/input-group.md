# Input Group 输入组

<a class="VPButton medium alt" href="https://shadcn-vue.com/docs/components/input-group" target="_blank" rel="noreferrer">shadcn-vue文档</a>

`UiInputGroup` 将输入框、前后缀和操作组合为一个整体。

## 基础用法

<div class="vp-demo">
<UiInputGroup><UiInputGroupInput placeholder="搜索" /></UiInputGroup>
</div>

```vue
<UiInputGroup><UiInputGroupInput placeholder="搜索" /></UiInputGroup>
```

## 组成

使用 `UiInputGroupAddon`、`UiInputGroupText` 和 `UiInputGroupButton` 添加前后缀与操作。
