# Popover 浮层

<a class="VPButton medium alt" href="https://shadcn-vue.com/docs/components/popover" target="_blank" rel="noreferrer">shadcn-vue文档</a> <a class="VPButton medium alt" href="https://reka-ui.com/docs/components/popover" target="_blank" rel="noreferrer">reka-ui文档</a>

`UiPopover` 在触发元素旁显示富内容浮层。

## 基础用法

<div class="vp-demo">
<UiPopover><UiPopoverTrigger>打开</UiPopoverTrigger><UiPopoverContent>内容</UiPopoverContent></UiPopover>
</div>

```vue
<UiPopover><UiPopoverTrigger>打开</UiPopoverTrigger><UiPopoverContent>内容</UiPopoverContent></UiPopover>
```

`UiPopoverAnchor` 可用作浮层定位锚点。
