# Tags Input 标签输入

<a class="VPButton medium alt" href="https://shadcn-vue.com/docs/components/tags-input" target="_blank" rel="noreferrer">shadcn-vue文档</a>

<a class="VPButton medium alt" href="https://reka-ui.com/docs/components/tags-input" target="_blank" rel="noreferrer">reka-ui文档</a>

将已输入值显示为可删除标签，并保留连续输入能力。

## 基础用法

<div class="vp-demo">
<UiTagsInput />
</div>

```vue
<UiTagsInput v-model="tags" />
```

## 组件组成

UiTagsInput、UiTagsInputItem、UiTagsInputInput、UiTagsInputItemDelete。

## 使用说明

请结合实际业务状态通过 `v-model`、属性和事件进行控制。
