# 多语言

组件内置简体中文（`zh-CN`）和英语（`en-US`）。`UiConfigProvider` 的 `locale` 接收语言代码。运行时更新这个值，组件的默认文案、无障碍标签和日历区域格式会随之切换。省略 `locale` 或传入未支持的代码时，使用简体中文。

项目已经使用 Reka UI 的 `ConfigProvider` 时，也可以直接设置它的 `locale`。组件会通过 Reka UI 的 `useLocale()` 读取语言代码。

## 运行时切换

```vue
<script setup lang="ts">
import { ref } from 'vue'

import { ConfigProvider as UiConfigProvider } from '@/components/ui/config-provider'

const locale = ref('zh-CN')
</script>

<template>
  <button type="button" @click="locale = 'zh-CN'">简体中文</button>
  <button type="button" @click="locale = 'en-US'">English</button>

  <UiConfigProvider :locale="locale">
    <UiCombobox :options="[]" />
    <UiDatePicker />
    <UiPaginationApp :total="100" />
  </UiConfigProvider>
</template>
```

示例中的三个展示组件使用项目现有的自动导入配置。应用也可以把 `UiConfigProvider` 放在根布局中，直接绑定应用的语言代码，例如 `vue-i18n` 中使用的 `zh-CN` 或 `en-US`。

## 覆盖组件文案

现有文案 props 和插槽仍可使用。例如，设置 `UiCombobox` 的 `placeholder` 会覆盖语言包的占位符。日历显式传入的 `locale` 优先于 Provider，日期选择器的 `valueFormat` 继续决定输出值格式。

业务表单标签、接口错误、地图底图与地名由使用方或对应服务提供。

自定义组件可从 `@/components/ui/config-provider` 导入 `useUiLocale`，并在 `setup` 中调用。在模板或事件处理函数中调用 `t('common.confirm')` 就会读取当前语言。也可以监听返回的 `locale` 来更新格式化器。
